# Transportation & Logistics Analytics Dashboard

This repository contains an end-to-end **Microsoft Power BI** project for logistics analytics.

## Repository Structure

- Transportation_And_Logistics_Dashboard.pbix
- Logistics_Transportation_Dataset.xlsx
- Dashboard.png
- README.md

## KPIs
- Total Revenue
- Total Cost
- Total Profit
- Total Shipments
- Delivered Shipments
- Delivery Success Rate

## Visuals
1. Filled Map
2. Donut Chart (Shipment Status)
3. Treemap (Top Shipment Cities)
4. Stacked Column Chart (Shipments by Warehouse)
5. Waterfall Chart (Profit by Vehicle Type)
6. Donut Chart (Revenue by Vehicle Type)
7. Ribbon Chart (Shipment Status Trend by Warehouse)
8. Matrix (Warehouse Performance Summary)
